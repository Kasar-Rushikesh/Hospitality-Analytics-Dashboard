# 🏨 Hospitality Analytics Dashboard

An interactive Hospitality Analytics Dashboard created using Business Intelligence tools to analyze hotel bookings, revenue, occupancy, cancellations, customer trends, and property performance.

---

## 📌 Project Overview

This project helps hotel businesses track and improve performance using data-driven insights.  
The dashboard provides a complete overview of:

- Total Revenue
- Total Bookings
- Occupancy Rate
- Cancellation Rate
- Capacity Utilization
- Revenue by City
- Revenue by Property
- Revenue by Room Class
- Weekday vs Weekend Analysis
- Weekly Trend Analysis

---

## 📊 Dashboard Features

### KPI Cards
- Total Revenue
- Occupancy %
- Cancellation Rate
- Total Bookings
- Utilized Capacity

### Charts & Visuals
- Revenue by City
- Revenue by Property
- Revenue by Room Class
- Booking Status Distribution
- Weekly Revenue Trends
- Occupancy Trends
- Weekday vs Weekend Comparison

### Filters / Slicers
- Month
- Week Number
- City
- Property Name
- Room Category
